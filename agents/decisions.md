# Workflow decisions

Fresh project baseline: no project-specific decisions, approvals or exceptions are recorded. The reusable workflow rules are defined in doctrine.md and stage-contracts.md. Copying this template grants no assignment or execution authority.

For each future governance decision, retain its identifier, context, decision, alternatives, consequences, issuer, approval source and effective revision. Exceptions additionally need exact scope and expiry. Record decisions only from actual project approvals.
