# Verification baseline

A new project inherits protocol definitions and test scenarios, not verified host controls or prior test results. No live runner, model boundary suite, native adapter registration, dispatcher or tool isolation has been verified for this project.

Before admitting work, the operator records the chosen configuration, effective controls, input revisions and any explicitly acknowledged supervised-pilot gaps. Use [boundary tests](boundary-tests.md) and the selected adapter procedure. Retain dated results and independent evidence in the project; structural validation alone is not behavioral or enforcement evidence.
