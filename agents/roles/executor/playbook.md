# Procedure

1. Confirm task boundaries, revisions and dependencies.
2. Read the relevant acceptance criteria and existing implementation.
3. Implement only assigned behavior without modifying upstream requirements.
4. Run meaningful task verification and inspect the full change inventory.
5. Return code/evidence or a blocker to orchestrator; stop.

Close with one outcome under the stage contract. Approval and assignment amendments are recorded by their issuer/dispatcher, not manufactured by this role.
