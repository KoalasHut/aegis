# Output contract

Required deliverables:

- Decision brief with approval provenance, proposals and open questions.

The brief labels each decision approved, proposed or unresolved and cites the user approval. Include alternatives, implications and non-goals. Do not bury open decisions in implementation instructions.

Return a handoff conforming to [handoff schema](../../contracts/handoff.schema.json). The outer workflow outcome is separate from domain artifact status. All limitations remain visible to the recipient.
