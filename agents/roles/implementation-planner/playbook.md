# Procedure

1. Pin the generic backlog and contract revisions.
2. Inspect the named target and document gaps.
3. Map every generic obligation to one or more tasks with acceptance IDs.
4. Add framework-specific work, file ownership and dependency constraints.
5. Escalate incompatible requirements; return a plan only when executable.

Close with one outcome under the stage contract. Approval and assignment amendments are recorded by their issuer/dispatcher, not manufactured by this role.
