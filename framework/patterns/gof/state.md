# State

## Intent
Makes meaningful behavior transitions explicit.

## Triggering Condition
Allowed behavior depends on lifecycle state.

## When To Use
Declare transitions and guards.

## When Not To Use
Avoid for values with no behavioral transitions.

## Architectural Consequences
Every transition preserves invariants.

## Related Framework Rules
DES-006, DOM-004

## Example in capability terms
Publication transitions from absent to published.
