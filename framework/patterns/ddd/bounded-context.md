# Bounded Context

## Intent
Defines a boundary within which terms have one meaning.

## Triggering Condition
Terms or policies differ across domains.

## When To Use
Name one context owner and publish translation contracts.

## When Not To Use
A folder alone does not create a semantic boundary.

## Architectural Consequences
Cross-context exchange requires explicit mappings.

## Related Framework Rules
CORE-002, DOM-001, DOM-003

## Example in capability terms
Training authoring defines approved lesson version.
