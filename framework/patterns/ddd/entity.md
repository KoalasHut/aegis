# Entity

## Intent
Represents continuity of identity through change.

## Triggering Condition
Identity matters independently of attributes.

## When To Use
Define identity meaning and lifecycle.

## When Not To Use
Use a value object when equality is by value alone.

## Architectural Consequences
Changes preserve identity and invariants.

## Related Framework Rules
DOM-001, DOM-004

## Example in capability terms
A lesson retains its identity across authoring revisions.
