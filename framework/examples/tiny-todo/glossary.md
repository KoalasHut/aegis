# Tiny TODO glossary

This unregistered illustrative context describes a personal task list. Its
records demonstrate the language and are not product approval records.

| Term | Meaning | Avoid as a synonym | Example |
| --- | --- | --- | --- |
| Task | A recorded item a person intends to finish. | Ticket | "Write outline" is a task. |
| Position | A task's place in the person's ordered list. | Rank | The first task has position 1. |
| Complete | Mark a task as finished without removing it from the list. | Delete | A completed task can be reopened. |
| Reopen | Mark a completed task as unfinished again. | Recreate | Reopening keeps its position. |
| Due time | The instant by which a task should be finished. | Reminder | A task can become overdue after its due time. |
| Overdue | The urgency state for an unfinished task whose due time has passed. | Late notification | A task due yesterday is overdue. |
