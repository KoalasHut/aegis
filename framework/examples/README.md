# Illustrative examples

`tiny-todo` is the primary worked example. It contains a bounded context,
structured decisions, contracts, domain rules, and executable scenarios. It is
illustrative and unregistered; it is not product approval or a project contract.

`core-preservation` is an advanced isolated example of the rule-catalog domain.
It has its own decisions, contracts, rules, and scenarios. Example scopes do
not satisfy project references or each other's references.
