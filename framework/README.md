# Aegis framework

This directory contains reusable rules and specification templates. Begin with the [constitution](constitution/constitution.md), [block language](language/block-spec.md), and the assigned role under [agents](../agents/README.md). The [architect role](../agents/roles/architect/agent.md) consolidates approved decisions into Concept Packs; implementation requires the later planning and execution assignments.

Copy the [block template](templates/block/concept.md) into `blocks/<context>/<capability>/` only within an authorized assignment. Templates are incomplete and are not approved contracts. Add domain vocabulary under [contexts](contexts/README.md), then index reviewed artifacts in the [registries](registry/README.md).

The starter contains no product contexts, registered blocks, public contract registrations, active waivers, historical decisions, or inherited approvals. [Decisions](decisions.md), [open questions](open-questions.md), and [validation](validation.md) start fresh for each project. Examples in pattern documents illustrate a technique; they do not establish project requirements.

Schemas validate artifact structure. They do not resolve references, approve semantics, enforce runtime behavior, or install host controls. See the [agent doctrine](../agents/doctrine.md) for assignment and evidence requirements.
