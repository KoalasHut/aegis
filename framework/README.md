# Aegis framework

This directory holds the core that should outlive an implementation: decisions, domain rules, vocabulary, expected behavior and capability contracts. Begin with the [constitution](constitution/constitution.md), [domain-rule specification](language/domain-rule-spec.md), [scenario specification](language/scenario-spec.md), [block language](language/block-spec.md), and the assigned role under [agents](../agents/README.md). The [architect role](../agents/roles/architect/agent.md) consolidates owner-reviewed rules, scenarios and glossary into consistent Concept Packs; implementation requires the later planning and execution assignments.

Use the [context templates](templates/context/) for glossary, themed domain rules and structured scenarios under `contexts/<context>/`. Copy the [block template](templates/block/concept.md) into `blocks/<context>/<capability>/` only within an authorized assignment, referencing the context's BR-/SC- IDs. Templates are incomplete and are not approved contracts. See [contexts](contexts/README.md), then index reviewed artifacts in the [registries](registry/README.md).

Project contexts and registries start empty. Reusable [framework decisions](decisions.md) describe Aegis maintenance choices, not approvals for a generated project's product. Teaching examples illustrate a technique; they do not establish project requirements or inherited conformance evidence. Keep project [open questions](open-questions.md) and [validation evidence](validation.md) explicit.

Run the [validator](../scripts/validate.py) with `python3 scripts/validate.py` from the repository root after installing `requirements-dev.txt`. It checks supported artifact schemas, IDs, references and coverage, and reports neutrality warnings. See [validation](validation.md) for the scope and limitations. Semantic approval, runtime conformance and host controls remain independent responsibilities; a passing validator does not establish them. See the [agent doctrine](../agents/doctrine.md) for assignment and evidence requirements.
